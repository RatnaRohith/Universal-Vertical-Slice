# Production Gates

## Gate 1 — Design Ready
Exit criteria:
- [ ] Logline, player fantasy, pillars, scope, and out-of-scope agreed.
- [ ] Sequence list and mission end condition approved.
- [ ] Must-have requirements have stable IDs and acceptance criteria.
- [ ] Risk register reviewed.

## Gate 2 — Graybox Complete
- [ ] All spaces connected and traversable.
- [ ] Player controller and interaction work.
- [ ] Objectives progress from start to ending.
- [ ] Drone encounter is understandable and escapable.
- [ ] Full slice can be completed with placeholder content.

## Gate 3 — Feature Complete
- [ ] All Must requirements implemented.
- [ ] No known blocker/critical bugs.
- [ ] Retry/checkpoint restores all relevant states.
- [ ] UI and audio events integrated.

## Gate 4 — Content and Polish
- [ ] Hero and environment assets meet the art brief.
- [ ] Materials, lighting, VFX, and post-processing approved.
- [ ] Music and critical SFX mixed and checked.
- [ ] Subtitles cover all critical voice information.
- [ ] Performance profiled in a packaged build.

## Gate 5 — Release Candidate
- [ ] All Must tests pass.
- [ ] Full playthrough completed on target machine.
- [ ] Build version, release notes, controls, and known issues documented.
- [ ] Clean install/launch verified.
- [ ] Final package archived and reproducible.

Do not pass a gate based only on percentage complete. Every exit criterion must be checked or explicitly waived with an owner and reason.

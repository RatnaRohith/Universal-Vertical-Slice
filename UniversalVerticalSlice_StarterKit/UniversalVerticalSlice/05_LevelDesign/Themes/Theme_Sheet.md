# Theme Sheet — Kepler Industrial Sci-Fi

| Role | Name | Hex | Usage |
|---|---|---|---|
| Primary dark | Deep Space | #101820 | Backgrounds, shadows, UI base |
| Secondary | Steel Blue | #243B53 | Panels, architecture |
| Neutral | Cold Alloy | #AAB7C4 | Metal trim, readable surfaces |
| Interactive | Neon Cyan | #00D1FF | Valid interactables, active systems |
| Warning | Warning Amber | #F5A623 | Hazards, locked/unstable systems |
| Threat | Threat Red | #E84A5F | Drone alert, critical danger |
| Success | Signal Green | #56D364 | Restored/confirmed state, use sparingly |
| Text | Soft White | #EAF2F8 | UI text and high-contrast markings |

## Rules
- Do not communicate state by color alone; pair color with icon, shape, text, or sound.
- Check contrast at actual gameplay brightness and in grayscale.
- Cyan means usable/active; amber means caution/blocked/unstable; red means immediate threat.
- Reserve green for confirmed success, not general decoration.
